# OFDM-SM — Моделирование систем передачи данных

## Описание проекта

Данный проект реализует **модель системы передачи данных с модуляцией OFDM (Orthogonal Frequency Division Multiplexing)** и вариантами **пространственной модуляции (Spatial Modulation)**. Реализация выполнена в среде **MATLAB**, и предназначена для моделирования, анализа и оценки.

Проект демонстрирует полный цикл цифровой передачи данных: от кодирования и модуляции до демодуляции, декодирования и расчёта показателей качества канала.

---

## Основные функции и файлы

* **OFDM.mlx** — Основной скрипт (Live Script). Управляет процессом моделирования, вызывает все остальные функции поэтапно.
* **calculate_ber.m** — Расчёт вероятности битовой ошибки (BER) для переданных и принятых данных.
* **conv_encode.m** — Свёрточное кодирование исходной последовательности бит.
* **conv_decode.m** — Декодирование свёрточного кода (например, алгоритм Витерби).
* **encode.m** — Основная функция кодирования данных, включает вызов свёрточного кодера и интерливера.
* **decode.m** — Обратная операция — декодирование данных после демодуляции (деинтерливинг и свёрточное декодирование).
* **interleave.m** — Перемешивание битов (интерливинг) для повышения устойчивости к замираниям канала.
* **deinterleave.m** — Обратная операция интерливинга.
* **qpsk_modulation.m** — Модуляция битовой последовательности в символы QPSK.
* **qpsk_demodulation.m** — Демодуляция QPSK-сигнала обратно в битовую последовательность.
* **ofdm_modulation.m** — Реализация OFDM-модуляции: преобразование в частотную область, добавление циклического префикса и т.д.
* **ofdm_demodulation.m** — Демодуляция OFDM-сигнала: удаление циклического префикса и обратное FFT-преобразование.
* **multibeam.m** — Моделирование многолучевого (мультипутевого) канала связи, влияние искажений и шума.
